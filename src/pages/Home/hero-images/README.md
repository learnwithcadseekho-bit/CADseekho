# Hero slider images

Drop image files here (`.jpg`, `.jpeg`, `.png`, or `.webp`) — the home page
hero slider picks them up automatically and auto-slides through them. No
code changes needed.

- **Order**: slides play in filename order, so prefix with numbers:
  `01-cad-model.jpg`, `02-classroom.jpg`, `03-workshop.jpg`, etc.
- **Size**: 1200×960px (5:4 ratio), same ratio for every slide so the frame
  doesn't jump between slides. Export at 2x (2400×1920px) if you want extra
  sharpness on retina screens.
- **File size**: keep each image under ~300KB (JPG quality ~80% or WebP) so
  the home page still loads fast.
- One image is fine too — the slider just won't show dots or auto-advance.
